# Earlier marketing site

This dependency-free site is retained for historical design/reference use. The current marketing implementation is [site-v2](../site-v2/README.md); the actual browser product is [web](../web/README.md).

To build this earlier static site, run `node build-live.mjs` from this directory. Its output is `live-dist/`. Internal design notes and copy drafts have been archived outside the repository.
