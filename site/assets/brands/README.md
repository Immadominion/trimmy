# Official ecosystem marks

These vectors are first-party assets used as supplied on Trimmy's dark ecosystem rail. Their labels remain live HTML.

- `xrpl.svg` — `XRP Ledger - Symbol - White.svg` from the [official XRPL brand kit](https://xrpl.org/XRPL_Brand_Kit.zip).
- `flare.svg` — [Flare dark-background UI mark](https://raw.githubusercontent.com/flare-foundation/developer-hub/main/static/img/ui/flare.dark.svg).
- `fassets.svg` — [FAssets dark-background UI mark](https://raw.githubusercontent.com/flare-foundation/developer-hub/main/static/img/ui/fassets.dark.svg).
- `ftso.svg` — [FTSO dark-background UI mark](https://raw.githubusercontent.com/flare-foundation/developer-hub/main/static/img/ui/ftso.dark.svg).
- `confidential-compute.svg` — [Flare Confidential Compute dark-background UI mark](https://raw.githubusercontent.com/flare-foundation/developer-hub/main/static/img/ui/fcc.dark.svg).

The XRPL developer portal and Flare developer hub repositories are MIT-licensed. Brand and trademark presentation rules remain applicable; do not recolor, distort, rotate, or add effects to these files.

The black XRPL symbol used for deterministic illustration faceplate compositing is retained outside the deploy root at `design/landing-assets/brand/xrpl-symbol-black.svg`.
